# UNIPDS — Engenharia de Software em IA Aplicada

Repositório de exemplos práticos desenvolvidos para a disciplina de Engenharia de Software em IA Aplicada (UniPDS).

Cada exemplo é um projeto Node.js autocontido que demonstra conceitos de aprendizado de máquina e redes neurais usando JavaScript.

## Exemplos

| Exemplo | Descrição | Tecnologia |
|---------|-----------|------------|
| [exemplo-00](./exemplo-00/) | Classificação de clientes com rede neural (premium / medium / basic) | TensorFlow.js |

## Requisitos

- Node.js >= 18 e < 23
- npm

## Como executar

Cada exemplo possui seu próprio `package.json`. Entre na pasta do exemplo e execute:

```bash
npm install
npm start
```
